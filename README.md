# CloudWin 11 - One-Time Install Render & 1024terabox.com Backend

## What's New in v3
- **One-Time Windows 11 Install (`.win11_installed.lock`)**: Windows 11 is installed **only once** on your first login. Every time you open the app again (or log in from another phone with the same TeraBox account), it skips installation and directly boots your saved Windows 11 desktop.
- **Mobile Hardware Passthrough**: Automatically reads and displays your phone's real RAM and CPU inside Windows 11.
- **1024terabox.com Integration**: Connects directly to `https://www.1024terabox.com/`.
